# Простая гонка

Небольшая игра на HTML Canvas с регистрацией, авторизацией и таблицей результатов.

## Как запустить

Нужна версия Node.js 22.5+ (проверено на Node 24). Внешние библиотеки не нужны.

Откройте терминал в папке проекта и выполните:

```bash
node server.js
```

Затем откройте в браузере:

```
http://localhost:3000
```

Файл `game.db` (база данных SQLite) создастся автоматически при первом запуске.

> Важно: просто двойным кликом по `index.html` игра запустится, но вход и сохранение результатов работать не будут — API доступен через сервер.

## Как выложить на хостинг (Render, бесплатно)

1. Зарегистрируйтесь на <https://render.com> через GitHub.
2. Создайте новый репозиторий на GitHub и загрузите туда содержимое этой папки.
3. В Render нажмите **New + → Blueprint** и выберите этот репозиторий.
4. Render сам прочитает `render.yaml`, установит Node 24 и запустит `npm start`.
5. Готово — адрес сайта будет вида `https://simple-race.onrender.com`.

Альтернатива: **New + → Web Service** → выберите репозиторий → `Build Command: npm install`, `Start Command: npm start`.

Проверка, что сервер живой: `https://ваш-адрес.onrender.com/api/health` должен вернуть `{"ok":true}`.

> На бесплатном тарифе Render файл `game.db` может сбрасываться при перезапуске сервиса (бесплатный диск не постоянный). Для домашнего задания это обычно допустимо. Если нужна постоянная база — используйте платный Postgres или persistent disk.

## Как считаются очки

- 1 очко за каждые 10 метров дистанции.
- 50 очков за каждый обгон машины соперника.

Результат сохраняется в базу данных, если игрок вошёл в аккаунт. Таблица показывает 10 лучших результатов.

## Что такое мидлвэйер

Мидлвэйер — это функция, которая выполняется перед основным обработчиком запроса. В `server.js` их три:

- `jsonMiddleware` — читает JSON из тела запроса в `req.body`;
- `sessionMiddleware` — находит пользователя по cookie и кладёт его в `req.user`;
- `requireAuth` — не пускает дальше, если пользователь не вошёл.

Например, сохранение результата использует сразу все три:

```js
middlewares: [jsonMiddleware, sessionMiddleware, requireAuth]
```
